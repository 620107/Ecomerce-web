NOVA MARKET — VERCEL DROP PACKAGE

This ZIP is intended for https://vercel.com/drop. Extracting is not required; upload the ZIP directly.

WHAT'S INCLUDED
- Home, About, Services, Contact, Help, Login and Register pages
- Responsive layout for mobile, tablet and desktop
- Product categories, search, wishlist button and shopping bag
- Cart state saved in the visitor's browser
- Contact/newsletter/auth demo forms

IMPORTANT
This is a polished front-end demo only. Login/register do not create real accounts. Contact/newsletter forms do not send emails, and checkout does not process payments. Connect a backend/auth provider, email service, and payment provider before taking real orders.
Product imagery and fonts are loaded from external services, so an internet connection is required.
